# Scientific Validation Performance

Respond in English. Define measurable acceptance gates before tuning. Use seeded synthetic ground truth and separately held-out real examples; avoid fitting and assessing on the same frames. Quantify false removal of valid science pixels, artifact recall, boundary error and uncertainty across instruments, shapes and noise levels. Include null images and confounders. Check pixel identity, metadata/WCS invariants, generated FITS CREATOR/DATE/HISTORY, kept-image symlink targets, reproducibility, serial/parallel equivalence and fault recovery. Cross-check FITS interoperability with an independent reader and fitsverify when available. For optional FITS visualizations, independently compare display scaling, panel geometry, orientation and representative samples against a reference implementation. Benchmark wall time, throughput, peak memory and I/O across image sizes and worker counts with recorded hardware/configuration. Optimize measured bottlenecks without weakening science thresholds; parallelize independent files with memory bounds and verified library thread safety. Document results under output/ and the reproducible procedure in `input/doc/`. Mark empirical claims unvalidated until evidence exists.

Group dataset splits by observing sequence/night/instrument and keep near-duplicates together. Repeatedly inspected examples are development data. Separate calibration from untouched final evaluation; report label ambiguity, annotator agreement, prevalence, domain support and failure/abstention rates. Use independent groups and justified spatial blocks for uncertainty, not pixel-wise independence. Calibrate the complete candidate/scale/region selection procedure before reporting significance or probabilities. Freeze metrics and practical gain thresholds; lack of statistical significance with low power is not equivalence.

For FITS action/reason sidecars, independently check the documented code range and precedence, exact alignment with the binary action mask, original undefined-pixel handling, source geometry and dimensionless units. Review source observational-card preservation and each product kind's explicit added/changed-card policy; do not accept an unexplained header difference as harmless.

Evaluate removal precision and recall together with valid retention, residual contamination, source/trail completeness and boundary error; count original undefined pixels separately. Validate geometry against independent small-grid oracles with stated pixel-center/footprint conventions. Profile stage-level live buffers and I/O before optimization, then use paired repeated release measurements and workload strata. Speed-only changes must preserve scientific outputs; tolerance-changing numerical optimizations require their own science evaluation. Never infer a hard RSS bound from a bytes-per-pixel estimate alone.

For detector changes, compare the configured default and each opt-in reference/evidence model on the same deterministic null, gradient, border-seam, source-confounder, rank-deficient and boundary-phase fixtures. For multiscale consensus, assert the minimum scale-vote rule on every proposed pixel and compare its final mask to the baseline. Verify that a model's algorithm identity is present in reports/logs, that abstentions remain explicit, and that experimental methods do not silently replace the default. Synthetic success is method evidence only; promotion still needs grouped labels, source-loss/photometric evaluation and held-out validation.
