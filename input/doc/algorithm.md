# Initial border detector

The current detector is an engineering baseline for large, border-connected regions. It divides a two-dimensional image into square tiles. For each tile it measures the finite-sample median and scaled median absolute deviation. It estimates the image interior from central tiles, then compares each tile median with the median of those interior medians. Its contrast score divides the absolute difference by the larger of the robust tile-median dispersion, interior noise scale and a small relative numeric floor.

It also measures horizontal and vertical lag-one Pearson correlations from finite adjacent pixel pairs. Each direction uses max-magnitude rescaling and Welford covariance moments to avoid overflow and does not allocate a pair buffer. Correlation supports an already high-contrast tile; it is never sufficient alone. For a constant tile, correlation is undefined. A zero-dispersion region against a measurable zero-dispersion interior may still be selected if it has clear contrast. The detector labels 4-connected candidate components connected to any frame edge and gates each component independently by minimum tile count, area, evidence and provisional utility. A component cannot borrow support from a disconnected region. Combined accepted components still pass image-level fraction and utility gates. It expands accepted tile selections to whole tiles.

The default `evidence_model = "single_scale"` retains one configured tile width. Opt-in `multiscale_consensus` runs widths `max(4, tile_size/2)`, `tile_size`, and `min(2*tile_size, floor(min(width,height)/3))`, deduplicating equal sizes. Each scale must independently pass the existing component and image gates; a final pixel is proposed only when at least two accepted scale masks select it. The consensus mask receives the image-level area, evidence, and utility gates again. Unsupported scale sets and insufficient or rejected consensus keep the source. Scale persistence is a deterministic robustness feature, not a probability or confidence estimate; the mode costs up to three detector passes and remains opt-in without shifted origins or external calibration. Algorithm IDs distinguish multiscale and reference-model combinations.

The default `reference_model = "central_tiles"` retains this baseline. An opt-in `reference_model = "robust_affine"` fits a plane to normalized central-interior tile centers and medians using up to ten Huber IRLS updates. It scores each tile against the fitted level, with contrast scale set by the robust interior residual dispersion, median tile MAD and a relative numerical floor; its quiet-tile gate uses median interior MAD. Rank-deficient, non-finite or undersupported fits abstain as `reference_fit_abstained` rather than falling back. This experimental fit does not detect/exclude compact sources from its reference samples, has no uncertainty map, and has not been calibrated on labeled observatory data. Reports and run-start logs identify it as `tile-detector-v1-robust-affine-experimental`; do not treat it as a science-grade replacement.

The detector supports asymmetric and partly symmetric regions through the connected-component mask. Decisions use image pixel statistics and mask geometry; object names, instrument labels, WCS values and other descriptive FITS cards are not detector evidence. FITS shape, storage/scaling and null-value cards are still needed to decode samples. Integer analysis abstains when a stored-value span exceeds exact f64 integer representation; floating centering and correlation use overflow-resistant arithmetic. If an integer mask action has no unused BLANK code, the source is retained unchanged. Crop geometry is selected after pixel-statistics detection. The strict seed is the exact maximum-area axis-aligned rectangle excluding the detector mask and originally undefined samples. When `maximum_residual_artifact_fraction` is nonzero, a summed-area-table search evaluates a deterministic family expanded from each seed boundary. It never includes originally undefined samples; detector-flagged defined samples inside the candidate must remain under the configured fraction. Candidates also pass the valid-pixel sacrifice and utility gates. Search is capped at 100,000 rectangles and adapts the pixel step deterministically, including each full-image boundary. The selected rectangle maximizes area only within this bounded expansion family; it is not globally optimal over all tolerant rectangles. Reports record residual fraction and search count/step. Cropped FITS arrays have `NAXIS=2`, with `NAXIS1/2` equal to the selected rectangle width/height. Supported primary and alternate `CRPIX1/2` values are shifted by the zero-based crop origin. Recognized lookup-table or distortion WCS conventions prevent a safe crop; crop mode then applies accepted detections as a dimension-preserving mask (`crop_wcs_mask_fallback`). This metadata limitation does not influence detection. The residual ceiling is provisional, not calibrated to scientific ground truth; detector flags are not known-invalid pixel labels.

FITS structural cards are needed to decode dimensions, storage type, and HDU count. Integer and floating analysis buffers are centered on a finite/raw-sample median; `BSCALE/BZERO` are validated but do not shift detection values, so descriptive/scaling cards cannot change the detector decision for identical stored samples. Instrument, observation, and WCS metadata do not contribute to detection scores or geometry choice. An out-of-range `BLANK` card is ignored for pixel statistics; valid in-range integer `BLANK` samples and non-finite float values remain undefined. A new integer sentinel is chosen only when a generated product needs to mark additional undefined samples.

A score is not a p-value or probability: spatial pixels and tiles are dependent, detector thresholds have not been calibrated, and selecting the center as reference can fail when the usable field is off-center. Noise reduction and correlation can also occur in valid sky or astronomical structure. Ambiguous outputs should be retained by raising the contrast gate or lowering the maximum mask fraction. Never interpret this baseline as proof that masked pixels contain no science signal.

## Audit and next algorithm

Revision 2 of the [improvement plan](scientific-improvement-plan.md) (2026-10-29) adds observed synthetic counterexamples for the current default. An unrelated interior source can flip a border decision, because the quiet-tile reference uses the maximum interior tile dispersion. High-dispersion (flat-amplified) borders are never candidates. Bright edge sources and smooth, still-illuminated vignetting gradients can be removed through the raw lag-one correlation branch. These are design evidence, not error-rate estimates; the planned replacement is a source-masked background/noise model with two-sided, standard-error-based evidence and native-resolution boundaries.

The [2026-10-27 audit](scientific-audit-2026-10-27.md) demonstrated whole-tile over/under-removal; centered analysis fixes the large-BZERO invariance failure but does not change detector geometry. Components now receive independent provisional gates, but source protection and local boundary refinement are absent, and accepted candidates are not independently labeled artifacts. These are active work in the [scientific improvement plan](scientific-improvement-plan.md); no new classifier calibration is claimed.

## Optional crop preview

With `--mode crop --png`, each accepted crop receives a side-by-side grayscale PNG. The renderer independently estimates ZScale intervals from up to 1,000 finite, regularly strided samples in the original image and in the exact final crop, using Astropy/IRAF-style 0.25 contrast, 2.5-sigma rejection and five-iteration defaults. Each panel therefore matches how that FITS image is displayed on its own; grayscale intensities across panels are not a shared photometric scale. The source panel retains native pixel scale; the crop panel is uniformly scaled with nearest-neighbor sampling to fill its display height while preserving aspect ratio and is labeled `CROP FIT`. Both panels use lower-origin FITS orientation; invalid source samples render black. PNG intensity is a visualization only and does not affect detection, crop geometry or FITS sample values.

The temporary `--reason-mask` diagnostic uses one byte code per original-frame pixel and is removed before program exit. `RSCHEME=PIXACT2`: `0` retained defined unflagged sample, `1` detector-selected artifact exclusion, `2` crop-only defined-pixel sacrifice, `3` pre-existing undefined sample, and `4` detector-flagged sample retained in a residual-tolerant crop. Pre-existing undefined samples take precedence over exclusion bookkeeping. This plane records the chosen program action only. It must not be interpreted as astrophysical validity, detector confidence, or an independent mask of true artifacts.


Transient mask and reason-mask FITS sidecars are used only during processing/verification. Their `masks/` and `reason_masks/` directories are removed before the summary is written and before exit. Reports retain pixel counts and decision reasons but do not include paths or manifest checksums for deleted sidecars.
